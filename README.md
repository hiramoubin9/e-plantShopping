# e-plantShopping

## Paradise Nursery Shopping Application

e-plantShopping is a React-based shopping cart application for Paradise Nursery, an online plant shop offering a variety of houseplants.

### Features

- Landing page with Paradise Nursery information
- Product listing page with multiple plant categories
- Plant images, names, descriptions, and prices
- Add to Cart functionality
- Dynamic shopping cart quantity
- Shopping cart with increase, decrease, and delete controls
- Automatic subtotal and total cost calculations
- Continue Shopping button
- Checkout button with a "Coming Soon" message
- Redux Toolkit for managing shopping cart state

### Technologies

- React
- Vite
- Redux Toolkit
- React Redux
- CSS
